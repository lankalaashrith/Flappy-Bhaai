# 🩸 ALLU HUB

A fast-paced, high-voltage HTML5 arcade game featuring **Bhaai** as the sole playable character, Stranger Things-inspired glowing neon typography (**ITC Benguiat Bold Condensed**), custom meme pillar obstacles, a 25-panel dynamic shuffled meme background reel, randomized cyclic dialogue audio clips on every retry, procedural sound FX, and full touch support.

## ✨ Features
- **Grand Cinema Title: ALLU HUB**: Enlarged glowing red Stranger Things neon typography using **ITC Benguiat Bold Condensed** (70px tall capitals, 4px neon top bar and flanking underlines).
- **Start Screen Instruction**: "Tannulu Tannulu undi inka , Chusthava" (single line, large bold font).
- **Start Screen Button**: "Start 10gulu"
- **Game Over Banner**: "AIPOYINDI BHAAI"
- **Sound Toggle (Top Left)**: Sound on/off button (`🔊` / `🔇`) pinned on the top left of the screen during gameplay and menus.
- **Randomized Audio Playlist on Every Turn**: Shuffles the 7 iconic dialogue clips randomly every single time you start or retry, playing cyclically until game over.
- **Fixed, Non-Disturbed Numbers**: Smooth vector stroke rendering (`-webkit-text-stroke: 1.8px #0f172a; paint-order: stroke fill;`) using bold arcade numerals—eliminating all jagged tearing artifacts.
- **25 Standardized Meme Backgrounds**: All 25 images processed to the exact same dimensions & aspect ratio (**540 × 795**) with smooth film-strip edge vignettes.
- **Randomized Shuffling Every Turn**: On every game start, retry, or return to menu, the entire deck of 25 background images is shuffled in a new random order!
- **Sole Character: Bhaai**: High-resolution transparent face cutout loaded with a signature crimson neon aura.
- **Custom Obstacle Bars**:
  - **Upper Bars**: Upright meme pillars.
  - **Lower Bars**: Vertically inverted (flipped) meme pillars.
